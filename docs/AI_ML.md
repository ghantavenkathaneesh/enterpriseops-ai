# AI / ML methodology

## Models

| Model | Algorithm | Input | Output |
|---|---|---|---|
| Incident classifier | TF-IDF (1-2 grams) + Logistic Regression (scikit-learn pipeline) | ticket text | category (network, hardware, software, access, database) + confidence |
| Anomaly detector | Isolation Forest (200 trees, contamination 0.03), trained on normal readings only | CPU, RAM, disk, network Mbps | anomaly flag + decision score |

Recommendations (`/recommend-actions`) are **static, human-written lists per category**, not model output, and are labelled as needing human review.

## Data provenance

**All data is synthetic**, generated by `scripts/generate_data.py` (seeded, reproducible):
- 1,500 tickets from 5 categories built from phrase templates, with 4 % random label noise.
- 3,000 metric rows from normal distributions with 90 injected anomalies.

No real tickets or infrastructure data were used.

## Results (from `models/evaluation.json`, actual run)

- Classifier, 20 % hold-out: accuracy 0.96, macro F1 0.96.
- Anomaly detector, 30 % hold-out (900 rows, 27 anomalies): precision 0.587, recall 1.0, F1 0.74.

## Limitations (read before quoting any number)

1. The ticket text comes from a small set of templates. Only 903 of the 1,500 rows are unique, so the hold-out set shares templates with the training set. **The 0.96 accuracy is optimistic and says nothing about real helpdesk text.**
2. Injected anomalies are easy to separate (extreme values), so recall of 1.0 is expected. The 0.59 precision means about 4 in 10 alerts are false alarms on this data.
3. Real use needs real labelled tickets, a drift check and periodic retraining.
4. Threshold rules in the backend run alongside the model, so alerts are not purely ML-driven.
5. The saved `.joblib` models are tied to the scikit-learn version. The Docker image retrains at build time to avoid mismatch.

## Reproduce

```
cd ai-service
python scripts/generate_data.py
python scripts/train.py        # writes models/*.joblib and models/evaluation.json
python tests/test_models.py    # or: pytest
```
